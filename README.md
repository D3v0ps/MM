# Miljonmatch

Miljonbemannings plattform för arbetsmarknadsinsatser. Se `CLAUDE.md`, `SPEC.md` och `docs/ARKITEKTUR.md`.

- Riktiga appen: Next.js (`src/app`), körs med `npm run dev`.
- Prototypen: samma kod byggd till en HTML-fil med `npm run demo:build`.
- Den gamla, fristående prototypen ligger kvar i `prototyp/` tills den nya har samma innehåll.
